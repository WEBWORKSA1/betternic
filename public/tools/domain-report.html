Domain Report

Run a complete free domain report: registration data, DNS, estimated value, brandability, website history and trademark checks in one place.

The Domain Report is the fastest way to size up any domain name before you buy it, price it or pitch it. Type a domain and BetterNic runs six checks at once: live registration data from the registry's RDAP service, DNS records, an automated value estimate, a brandability score, Internet Archive history and one-click trademark searches in the major offices.

Investors use it as a first-pass filter. Brokers use it to prepare for a call with a seller. Startups use it to check whether the name they love is already a company, a spam domain or a trademark problem. Everything runs in your browser against public data sources, and nothing you type is stored by BetterNic.

How to use the Domain Report

  1. Enter a domain such as example.com (URLs and www are cleaned automatically).
  2. Press Run report. Registration, DNS and history load in parallel within a few seconds.
  3. Read the value and brandability breakdowns to see exactly which factors moved the score.
  4. Open the trademark links to search each office with the name pre-filled.
  5. Use the action buttons to list the domain, request a broker, or save it to your portfolio.

How it works

Registration data comes from RDAP (Registration Data Access Protocol), the ICANN-mandated successor to WHOIS. BetterNic looks up the correct registry server from the IANA bootstrap file, refreshed daily, and falls back to rdap.org. DNS is resolved through public DNS-over-HTTPS resolvers. History uses the Internet Archive's Wayback Machine availability and CDX APIs. Value and brandability use the open BetterNic model explained on the appraisal page.

A registry that does not publish RDAP (some country-code extensions) will show as "no RDAP service" — that is a limitation of the registry, not proof that the domain is free.

When to use it

  • Due diligence before bidding at auction or making an offer
  • Preparing a valuation discussion with a buyer
  • Checking a startup name for conflicts before you register it
  • Spotting expired domains with a spam past

Pro tips

  • An expiry date within 45 days plus no website and no MX record often signals an owner who may sell or drop.
  • A long, continuous Wayback history usually means real type-in traffic and backlinks — and higher value.
  • Always read the trademark results yourself; automated flags only catch famous brands.

Frequently asked questions

Is the domain report really free?

Yes. There is no sign-up and no limit beyond the rate limits of the public data sources it queries.

Why does the report say 'no RDAP service'?

Some country-code registries have not deployed RDAP. Use the registry's own WHOIS website for those extensions.

How accurate is the value estimate?

It is an automated estimate for research. It cannot see traffic, comparable sales or buyer demand, so treat it as a starting point and get a human appraisal for important decisions.

Do you store the domains I check?

No. Lookups run from your browser directly to the public services. BetterNic does not log your queries.
